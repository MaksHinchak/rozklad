1-й / 2-й тиждень. У пари обираєш «Щотижня», «1-й (непарний)» або «2-й (парний)». Показуються лише ті пари, що є цього тижня. Застосунок сам чергує тижні за календарем — раз налаштуй у «Цей тиждень», далі перемикається автоматично. Кнопка 1-й/2-й тиждень угорі показує інший тиждень для перегляду.

Як перекинути на телефон:
1. «Зберегти файл з розкладом» → отримаєш rozklad.html з усіма парами всередині.
2. Надішли цей файл собі в Telegram (Збережене).
3. На телефоні відкрий файл → «Відкрити в браузері». Інтернет не потрібен.
4. Android: у Chrome «Додати на головний екран». iPhone: збережи у «Файли», відкрий у Safari.
