# Розклад 241-1

Однофайловий розклад пар, що працює без інтернету.

- `index.html` — увесь застосунок (розмітка, стилі, логіка і самі пари всередині)
- `sw.js` — service worker, кешує сторінку для офлайн-роботи
- `manifest.webmanifest` — щоб ставилось на головний екран як застосунок

Дані зберігаються локально в браузері (`localStorage`). Меню ☰ → «Зберегти файл
з розкладом» віддає копію `index.html` із зашитими всередину парами.

## Сторінки

- `/` — розклад 241-1
- `hw/` — домашки до нього
- `psy/` — розклад психології
- `psy/hw/` — домашки до нього

Кожна сторінка самодостатня: свій `index.html`, `sw.js`, маніфест та іконки.

## Домашки

Записник домашніх завдань у тому ж стилі. Предмети підтягуються з розкладу,
що лежить у батьківському шляху (читає ключі `rozklad_v1:` у `localStorage`);
якщо його немає — бере запасний список, зашитий у файл. Виконані завдання
зникають самі через 3 дні, термін змінюється в меню.

## Синхронізація

Обидва записники домашок уміють синхронізуватися через **приватний gist**
(меню → «Синхронізація»). Токен GitHub з правом лише `gist` вводиться один раз
на кожному пристрої і живе тільки в `localStorage` — у репозиторій він не
потрапляє ніколи. Gist знаходиться сам, за описом (`domashki-sync:main` /
`domashki-sync:psy`), тому на новому пристрої достатньо вставити токен.

Злиття поштучне, за `it.upd` кожного завдання, а не «останній переміг».
Видалене лишається міткою `{del:1}` на 30 днів — інакше інший пристрій
принесе його назад. Розклади не синхронізуються, лише домашки.

## Замок власника (тільки 241-1)

`/` і `hw/` знають режим власника: без входу розклад видно, але редагувати
його не можна, а домашки взагалі не показуються. Логін запам'ятовується
в `localStorage` (`adm_v1:main`) назавжди — питається один раз на пристрій.

Це замок на інтерфейсі, а не справжній захист: сторінка статична, і хто вміє
відкрити консоль — обійде. Реального витоку немає з іншої причини: домашки
не лежать ні на сервері, ні у файлах репозиторію, лише в браузері власника.

Пароль зашитий хешем (`AHASH` у файлі, функція `ahash`). Щоб змінити —
перерахуй `ahash(логін, пароль)` і встав нове значення в обидва файли.
Психологія (`psy/`, `psy/hw/`) навмисно без замка.
