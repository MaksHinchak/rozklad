# Розклад 241-1

Однофайловий розклад пар, що працює без інтернету.

- `index.html` — увесь застосунок (розмітка, стилі, логіка і самі пари всередині)
- `sw.js` — service worker, кешує сторінку для офлайн-роботи
- `manifest.webmanifest` — щоб ставилось на головний екран як застосунок

Дані зберігаються локально в браузері (`localStorage`). Меню ☰ → «Зберегти файл
з розкладом» віддає копію `index.html` із зашитими всередину парами.
